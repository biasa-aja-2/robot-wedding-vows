One line of wedding vows for a robot couple, written to get a laugh: a promise in the classic wedding cadence — "in sickness and in low battery" — with the punch in the last words, love that survives even a factory reset, because a backup restores what the reset takes.

## Run it

```sh
python3 main.py
```

Writes the vow (123 characters, one line) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Pure Python standard library, no dependencies. The program enforces the competition gate itself — 1–160 characters, single line, valid UTF-8, not blank — and verifies by reading the file back before exiting.
